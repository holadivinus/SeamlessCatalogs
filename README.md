# SeamlessCatalogs
Unity-Editor Tool to make working with Addressables easier.
Browse a pallet's Assets as if they were in your project,
And use them in Scenes & Prefabs.

### Install:
 \- Goto Unity -> Window -> Package Manager 
 \- Click the Top-Left + -> Add Package from git URL...
 \- Paste https://github.com/holadivinus/SeamlessCatalogs.git and press "Add".
